# CON-TRONCOCON-BOCC

Serbatoio cilindrico verticale con coperchio conico e fondo troncoconico
dotato di bocchello di fondo (tronchetto cilindrico applicato sotto la base
minore del tronco di cono).

Il bocchello (Ø e altezza, `dBocchello`/`hBocchello`) è opzionale: con
Ø = 0 il calcolo coincide con il fondo troncoconico senza bocchello.

Stato carta: `active`.
